### 2. Membuat Tabel HTML

Membuat halaman HTML dengan menggunakan elemen:

- `<table>` untuk membuat tabel.
- `<tr>` untuk membuat baris.
- `<th>` untuk membuat header tabel.
- `<td>` untuk membuat isi tabel.

**Hasil:**

![Tabel HTML](screenshot/tabel.png)

---

### 3. Membuat Form HTML

Membuat form untuk menerima input dari pengguna menggunakan
elemen `<form>` dan berbagai jenis input.

Contoh input yang digunakan:

- Text
- Radio button
- Checkbox
- Textarea
- Submit

**Hasil:**

![Form HTML](screenshot/form.png)

---

### 4. Menggunakan Semantic HTML

Menggunakan elemen semantic HTML seperti:

- `<header>`
- `<nav>`
- `<main>`
- `<section>`
- `<article>`
- `<aside>`
- `<footer>`

Elemen tersebut digunakan untuk membuat struktur halaman
lebih terorganisir dan memiliki makna yang jelas.

**Hasil:**

![Semantic HTML](screenshot/semantic.png)

---

### 5. Menambahkan Multimedia

Menambahkan multimedia ke dalam halaman HTML menggunakan
elemen `<audio>` dan `<video>`.

**Hasil:**

![Multimedia](screenshot/multimedia.png)

---

### 6. Membuat Validasi Form

Menambahkan atribut validasi HTML seperti:

- `required` untuk membuat input wajib diisi.
- `min` untuk menentukan nilai minimum.
- `max` untuk menentukan nilai maksimum.
- `minlength` untuk menentukan panjang minimum teks.

**Hasil:**

![Validasi Form](screenshot/validasi.png)
